# 💫 About Me:
Разработал проект с решением задач RuКод по ML и развернул на виртуальном сервере с использованием технологий Docker + FastApi.
По этой задаче на площадке соревнования набрал 96.56 баллов.
На сайте [https://www.alexslesarev.ru](https://www.alexslesarev.ru) можно проверить результаты работы проекта через форму для пользователя.
Использованы сгенерированные синтетические данные и модель обучена на них, чтобы не разглашать данные компании из соревнования.

## В разработке

### 🚀 Инфраструктура и деплой
 - [x] Настройка reverse proxy через Nginx для продакшн-деплоя
 - [x] Привязка домена и настройка HTTPS (Let's Encrypt)
- CI/CD pipeline для автоматического деплоя контейнеров

### 💻 Кодовая база
- Добавление полных docstring (Google Style) для всех публичных методов и эндпоинтов
- Интеграция логирования (structlog) с уровнями и ротацией файлов
- Типизация кода и проверка через `mypy`

### 📊 Данные и модель
- Улучшение генерации синтетических данных с более реалистичными статистическими связями с таргетом
- Добавление второй задачи RuКод (банковская сфера) в мультитасковый пайплайн

### ✅ Тестирование
- Написание unit-тестов для бизнес-логики (`pytest`)
- Тесты эндпоинтов FastAPI через `TestClient`
- Проверка воспроизводимости обучения модели
